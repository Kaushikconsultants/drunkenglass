# Design reference — working prototype

Open `index.html` and click through. All 14 pages, fully navigable.

## Demo credentials
- Trade sign-in: any work email + code **DG-DEMO**
- Order tracking: any ID starting **DG-**

## Pages
index.html / drunken-glass-comet.html — Homepage
drunken-glass-category.html — Shop
drunken-glass-pdp.html — Product page
drunken-glass-cart.html — Cart (GoKwik handoff)
drunken-glass-track.html — Track order
drunken-glass-trade.html — Trade login + policies + FAQ
drunken-glass-collection.html — Wholesale catalogue (gated)
drunken-glass-trade-orders.html — Trade dashboard: reorder, replenishment, calculator
drunken-glass-proforma.html — Proforma invoice (printable)
drunken-glass-gifting.html — Corporate gifting
drunken-glass-about.html — Our story
drunken-glass-contact.html — Contact
drunken-glass-policies.html — Shipping / Returns / Privacy / Terms
404.html — Not found

## IMPORTANT
This is a prototype, not production code. Every price, discount, minimum,
stock status and tax figure is hard-coded in the page and MUST be
re-implemented server-side. See Part 6 of the handover document.
